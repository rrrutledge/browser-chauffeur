# Legacy hook oracle

`legacy_hook.py` is a frozen copy of the original single-file
`allow-safe-compounds.py` as it existed immediately before the refactor into
the `safe_compounds/` package.

It exists for one purpose: `regen_golden.py` imports it to (re)derive
`fixtures/golden.json` — the canonical ALLOW/BLOCK/PROMPT decision for every
characterization case. The characterization test then proves the refactored
hook reproduces those decisions exactly.

Do not edit this file or wire it into the plugin. It is a historical reference,
not running code.
